# View in your room (WebXR AR) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A round AR button on the stage puts the moving mechanism on the reader's floor through WebXR `immersive-ar`, with the gauge on top and the dock at the bottom.

**Architecture:** The same renderer, scene and store enter an XR mode in the shell. A lazily loaded `src/core/xr` chunk requests the session with hit-test and DOM overlay, hides the environment, wraps the content in a placement group fitted into a 0.5 m cube, and handles placement and gestures. Leaving AR restores everything.

**Tech Stack:** TypeScript, three.js 0.186 (`renderer.xr`), WebXR Device API (hit-test, dom-overlay), zustand, i18next, vitest with happy-dom, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-13-webxr-ar-design.md`

## Global Constraints

- Read `ARCHITECTURE.md` sections "Contract", "Scene toolkit", "UI toolkit" and "Conventions" before touching `src/core`.
- `source ~/.nvm/nvm.sh && nvm use` before any npm command.
- Before every commit: `npx prettier --write <paths>`, `npx eslint <paths>`, `npx tsc --noEmit -p tsconfig.json`, `npx vitest run <paths>`.
- No comments in code. No all-caps words in text. Atomic conventional commits, scope `xr` unless the change is elsewhere. End each commit message with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Unit tests are `*.test.ts`; tests needing the DOM are `*.dom.test.ts`, next to the module.
- No new npm dependencies. WebXR types: use `@types/three`'s bundled `XRSession`/`XRFrame` types or the DOM lib; if missing, declare the minimal interfaces in `src/core/xr/types.ts`.
- Model fit size: `AR_MODEL_SIZE = 0.5` (metres). Pinch scale limits: `0.25` to `4` times the fitted size.
- AR is on by default; `scene.ar === false` turns it off.
- Session request: `navigator.xr.requestSession('immersive-ar', { requiredFeatures: ['hit-test'], optionalFeatures: ['dom-overlay', 'local-floor'], domOverlay: { root: stage } })`.
- Copy: short sentences, everyday words, warm second person, no em or en dashes as sentence punctuation in any language.
- The explainer JS budget (`JS_BUDGET_GZIP.explainer`, 300 000 gzipped bytes) must still pass: everything in `src/core/xr` except `support.ts` and `button.ts` is reached only through a dynamic `import()`.

## Review Focus

- The reader leaves AR with the system back gesture instead of the exit button: the page must come back fully (canvas visible, labels, background, fog, rig camera, normal loop). Test in Task 5 with a session `end` event fired directly.
- The camera permission is denied (`requestSession` rejects): nothing in the scene changes and `ar.failed` shows for 4 s. Test in Task 5.
- A tap on the dock or gauge while in AR must not place or move the model. Test in Task 5 that `beforexrselect` is prevented on both.
- An explainer starts with labels shown, a camera `follow` anchor or a tween in progress: after AR the rig pose equals the pose before AR. Test in Task 2.
- `isSessionSupported` rejects or `navigator.xr` is missing: no button, no thrown error. Test in Task 1.

- Produces: `AR_MODEL_SIZE = 0.5`; `prepareArScene(shell: SceneShell): ArScene` with `interface ArScene { anchor: Group; content: Group; fitScale: number; restore(): void }`. `anchor` is added to the scene and is what placement moves, turns and scales; `content` holds every former scene child except lights and the stage, offset so the fitted box's bottom centre sits at the anchor origin; `fitScale` is the uniform scale that fits the visible mechanism's bounding box (backdrop excluded) into a 0.5 m cube.

After `restore()`: every object's parent, local transform and visibility, fog, background and label layer equal the originals, and `anchor` is removed.

- [ ] **Step 1: Write failing tests** with a fake `XRSystem` and `XRSession` (an `EventTarget` with `requestReferenceSpace`, `requestHitTestSource`, `requestHitTestSourceForTransientInput`, `end`). Assert:
